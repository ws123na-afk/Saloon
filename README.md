# Saloon

Luxury one-page beauty studio website built with plain HTML, CSS, and JavaScript.

## Project Structure

- `index.html` — page content and sections.
- `styles.css` — visual styles and responsive breakpoints.
- `script.js` — UI interactions (menu, animations, slider, form UX).

## Run Locally

This is a static site, so you can open `index.html` directly, or serve it locally:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000`.

## Current Behavior

- Mobile navigation toggle with body scroll lock.
- Smooth scrolling for in-page anchor links.
- Scroll reveal and stat counter animations.
- Reviews slider with auto-rotation.
- Booking form confirmation UI (client-side only; no backend integration).

## Notes

- External fonts are loaded from Google Fonts.
- Social links and booking submission are placeholders unless integrated with real services.
